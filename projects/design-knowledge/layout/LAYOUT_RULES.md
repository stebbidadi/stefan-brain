# LAYOUT RULES

> Practical composition rules for posters, editorial work, portfolios, menus, social graphics, and identity applications.

## Reading Order First
- Decide what the viewer should notice first, second, and third.
- Make the hierarchy visible before adding decorative elements.
- Group information by meaning, not merely by available space.

## Alignment
- Use a small number of strong alignment axes.
- Align related elements even when they are separated spatially.
- Prefer deliberate asymmetry over accidental near-symmetry.
- Use optical alignment when shapes appear misaligned despite mathematical coordinates.

## Spacing & Rhythm
- Use a repeatable spacing family rather than random gaps.
- Related items should generally sit closer together than unrelated groups.
- Let important changes in spacing communicate section changes.
- Preserve breathing room around high-priority elements.
- Avoid distributing elements evenly simply to fill empty space.

## Hierarchy
Use contrast intentionally through one or more of:
- Scale
- Weight
- Position
- Density
- Tone / color
- Shape
- Direction
- Negative space

Do not change every variable at once when one or two are enough.

## Negative Space
- Treat empty space as an active structural element.
- Empty space can isolate, group, frame, pause, or increase emphasis.
- Do not fill space merely because it exists.

## Scale
- Strong scale differences usually create clearer hierarchy than many small incremental differences.
- Size should respond to viewing distance and format.
- Large elements may intentionally cross modules or crop, but the gesture should support the composition.

## Balance
- Visual balance does not require symmetry.
- Consider apparent weight: dark areas, large type, saturated color, dense texture, faces, and high-contrast images attract attention.
- Counterbalance heavy elements through position, space, scale, or secondary elements.

## Repetition & Consistency
- Repeat alignments, type styles, spacing values, rules, shapes, or image treatments to create a system.
- Repetition should build recognition without making every composition identical.

## Image + Type
- Crop for the message, not only to fit the box.
- Avoid placing important text over visually noisy image regions unless contrast is deliberately controlled.
- Align image edges/crop lines with the grid when that strengthens the system.
- Decide whether image or type leads; avoid having both fight equally for attention without purpose.
- When using multiple images, give them a clear relationship through scale, crop, spacing, or sequence.

## Modernist / New Typography Defaults
Useful when a rational modernist direction is appropriate:
- Asymmetric composition
- Strong horizontal/vertical relationships
- Clear geometric structure
- Limited visual vocabulary
- Strong scale contrast
- Type treated as a compositional element
- Functional use of rules, blocks, photography, and empty space

Do not reduce “Bauhaus” to red/yellow/blue circles and geometric decoration. Structural clarity and purposeful reduction are more important than superficial motifs.

## Breaking the System
Break a grid/alignment/spacing rule when the break:
- Improves hierarchy
- Creates useful tension
- Supports concept or meaning
- Directs attention
- Solves a content problem

If the exception has no communicative or expressive purpose, return to the system.

## Final Critique Checklist
- Can the main message be identified immediately?
- Is the intended reading order obvious?
- Are alignment relationships visible?
- Is spacing systematic?
- Is type readable at actual output size?
- Is the composition balanced without becoming static?
- Does empty space have a purpose?
- Are image crops intentional?
- Is there anything present only because the layout felt empty?
- Could one design move be removed without losing meaning?
