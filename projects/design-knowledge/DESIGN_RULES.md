# DESIGN RULES

> Routing note for design tasks. Read only the smallest relevant reference set.

## Routing
- Type choice, hierarchy, leading, kerning, measure, alignment → `typography/TYPE_RULES.md`
- Columns, modules, baseline grids, Bauhaus/New Typography, Swiss systems → `grids/GRID_SYSTEMS.md`
- Composition, spacing, balance, scale, image/text relationships → `layout/LAYOUT_RULES.md`
- Load more than one only when the task genuinely spans those areas.

## Default Design Method
1. Identify the communication goal and required information.
2. Establish reading order and hierarchy before styling.
3. Choose a grid appropriate to the amount and type of content.
4. Build typography with as few variables as possible.
5. Create relationships through shared alignments and repeatable spacing.
6. Use contrast deliberately: scale, weight, tone, color, position, density, or direction.
7. Make optical corrections after the mathematical system is working.
8. Break the system only when the break improves communication or expression.

## Critique Order
When reviewing a design, diagnose in this order:
1. Message / reading order
2. Hierarchy
3. Grid / alignment
4. Typography
5. Spacing / rhythm
6. Contrast / balance
7. Image treatment
8. Production constraints

Give concrete fixes rather than vague comments such as “make it pop.”

## Historical Note
“Bauhaus grid” is useful shorthand, but there was no single canonical Bauhaus grid. Bauhaus and New Typography work emphasized reduction, geometric structure, asymmetry, sans-serif type, and rational organization. Later Swiss/International designers developed more systematically codified column and modular grid practices.
