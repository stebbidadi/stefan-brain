# Design Knowledge

> Reusable graphic-design knowledge for ChatGPT. Load only the reference file needed for the current design task.

**Status:** Active  
**Last updated:** 2026-09-28

## Goal
Improve design assistance by keeping compact, durable rules for typography, grids, layout, and visual systems in one place.

## Core Files
- `DESIGN_RULES.md` — router + critique method
- `grids/GRID_SYSTEMS.md` — grid types, modernist/Bauhaus/New Typography, Swiss systems
- `typography/TYPE_RULES.md` — typography defaults and checks
- `layout/LAYOUT_RULES.md` — hierarchy, spacing, composition, image/text relationships

## Operating Principle
- Treat rules as informed defaults, not laws.
- Content, audience, format, production method, and intended expression can justify breaking a rule.
- Distinguish historical design characteristics from current practical recommendations.
- Prefer a small coherent system over many unrelated design moves.

## Current Coverage
- Bauhaus / New Typography principles
- Swiss / International grid logic
- Manuscript, column, modular, hierarchical, and baseline grids
- Core typography rules
- Core layout/composition rules
