# GRID SYSTEMS

> Practical grid defaults for graphic design. Use as systems, not cages.

## Grid Anatomy
- **Margins:** outer frame around the composition.
- **Columns:** vertical divisions for text/images.
- **Gutters:** space separating columns.
- **Modules:** repeated units created by intersecting rows and columns.
- **Baseline grid:** repeated horizontal rhythm, normally derived from body-text leading.
- **Spatial zones:** groups of modules assigned to recurring content types.

## Core Grid Types

### Manuscript Grid
One dominant text/content area.
Use for essays, books, statements, or layouts where continuous reading is primary.

### Column Grid
Multiple vertical columns.
Use when different content types must coexist or when text/image widths need flexibility.

### Modular Grid
Columns + horizontal divisions create repeated modules.
Use for complex editorial systems, catalogs, data-heavy work, identities, and layouts requiring strong repeatability.

### Hierarchical Grid
Alignment zones are defined by content relationships rather than equal modules.
Use when information has irregular sizes or a strongly expressive hierarchy.

### Baseline Grid
Horizontal lines based on body-text leading.
Use to maintain vertical rhythm and align text across columns/pages.

## Bauhaus / New Typography Principles
There is no single canonical “Bauhaus grid.” Use these as historically informed characteristics:
- Organize information rationally rather than decoratively.
- Prefer strong geometric relationships.
- Use asymmetry deliberately rather than default centered symmetry.
- Use a small number of clear alignment axes.
- Integrate type, rules, shapes, and images into one composition.
- Sans-serif type is historically characteristic, but the structural logic matters more than copying a visual style.
- Let empty space actively separate and organize information.
- Vary scale and placement to establish hierarchy while preserving underlying order.

## Swiss / International Grid Principles
- Establish a repeatable column/module system before styling details.
- Use shared edges and baselines to create relationships.
- Keep spacing systematic.
- Favor clear hierarchy and legibility.
- Flush-left / rag-right typography is a strong default for continuous Latin text.
- Photography and type should belong to the same structural system.
- The grid should enable many compositions without every page becoming identical.

## Starting Recipes
These are starting points, not standards.

### Poster
- 4–6 columns for simple posters.
- 6–8 columns for posters with several information levels.
- Use column combinations (e.g. 2+4, 3+3) rather than forcing every object into one column.

### Editorial / Portfolio
- 6, 8, or 12 columns provide flexible combinations.
- Set the baseline increment from body-text leading.
- Allow images to occupy multiple columns/modules.

### Social / Square Layout
- 4 or 6 columns usually provide enough structure without overcomplication.
- Preserve a strong safe margin before adding internal modules.

## Grid Construction Rules
1. Start from content requirements, not an arbitrary number of columns.
2. Establish margins first.
3. Choose a small number of columns that permit the widths you actually need.
4. Set gutters consistently.
5. Derive vertical rhythm from body-text leading when text is important.
6. Align related elements to common edges or baselines.
7. Use a consistent spacing unit or family of spacing values.
8. Combine modules for larger content rather than creating unrelated dimensions.
9. Make optical corrections when mathematically aligned objects still look wrong.
10. Break the grid deliberately, not accidentally.

## Signs the Grid Is Failing
- Too many unrelated alignment axes.
- Every element uses a different width.
- Gutters/margins change without reason.
- The grid forces poor line lengths or awkward image crops.
- The layout feels mechanically repetitive rather than coherent.
