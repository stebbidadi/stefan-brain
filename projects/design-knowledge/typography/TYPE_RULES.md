# TYPE RULES

> Practical typography defaults for graphic design. Treat numeric values as starting points, not laws.

## Hierarchy
- Establish the information hierarchy before choosing decorative treatments.
- Build hierarchy with as few variables as possible: size, weight, spacing, position, color, or case.
- Prefer using one strong type family well before adding multiple unrelated families.
- Make adjacent hierarchy levels visibly distinct; tiny differences often read as mistakes rather than intention.

## Body Text
- Choose a typeface that remains clear at the actual production size.
- A useful starting measure is roughly 45–75 characters per line for continuous text; adjust to format and typeface.
- Start leading around 120–150% of type size, then judge visually.
- Longer lines, dense faces, and some small sizes generally need more leading.
- Avoid setting body text so tightly that ascenders/descenders visually collide.
- Use paragraph styles for recurring text rather than formatting each block manually.

## Alignment
- Flush-left / rag-right is a strong default for continuous Latin text.
- Centered text works best for short, deliberate blocks rather than long reading text.
- Fully justified text needs enough line length plus careful hyphenation/word spacing; avoid obvious rivers.
- Keep alignment logic consistent across related elements.

## Rag, Widows & Orphans
- Shape the rag intentionally; avoid repeated obvious steps or awkward holes.
- Avoid a single short word stranded on the last line when practical.
- Avoid isolated first/last lines of paragraphs across columns/pages when practical.
- Manual line breaks are acceptable in display type when they improve composition and meaning.

## Kerning, Tracking & Spacing
- Kerning adjusts specific letter pairs; tracking changes overall letter spacing.
- Check display type manually, especially large headlines/logotypes.
- Keep lowercase body tracking close to the typeface’s intended spacing unless there is a clear reason to change it.
- All caps often benefit from modest positive tracking.
- Do not use tracking to compensate for a fundamentally wrong typeface choice.

## Leading
- Adobe’s default auto-leading is commonly 120% of type size; treat that only as a starting point.
- Body text normally needs more air than multi-line display type.
- Large display headlines may work with tighter leading, including values near or below the type size when shapes allow it.
- Judge leading together with line length, x-height, weight, and typographic color.

## Baseline & Rhythm
- When working on multi-column/editorial layouts, derive the baseline grid from the body-text leading.
- Use multiples or half-multiples of that rhythm for vertical spacing when it improves consistency.
- Do not force every element onto the baseline grid if doing so harms optical spacing or hierarchy.

## Typeface Pairing
- Pair typefaces because they create a useful relationship, not simply because they are different.
- Start with contrast in role: text/display, serif/sans, neutral/expressive, wide/narrow, etc.
- Avoid pairing faces that are only slightly different unless the subtlety is intentional.
- Check numeral styles, punctuation, accents, Icelandic characters, weights, and italics before committing to a family.

## Detail Checks
- Use proper quotation marks and apostrophes rather than straight keyboard marks in finished work.
- Use the correct dash for the language/context.
- Check punctuation spacing, numerals, currency, dates, and special characters.
- Use real small caps when available rather than scaled-down capitals.
- Consider hanging punctuation / optical margin alignment in refined editorial work.

## Display Type
- Readability can be traded for expression more aggressively than in body text, but the intended message still has to survive.
- Test the headline at actual viewing distance/size.
- Optical alignment matters more as type gets larger.
- Cropping, rotation, overlap, extreme tracking, or unusual line breaks should feel intentional and support the concept.

## Common Problems
- Too many typefaces or hierarchy styles.
- Weak contrast between hierarchy levels.
- Tight leading with long lines.
- Excessive tracking in lowercase.
- Centering everything by default.
- Arbitrary line breaks.
- Ignoring the rag.
- Using type size alone to solve hierarchy.
