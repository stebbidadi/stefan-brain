# ResPress

> BA Graphic Design final project exploring legibility versus resolution.

## Status
**Status:** Completed / Portfolio Reference  
**Last updated:** 2026-09-28

## Goal
Create an interactive system for exploring how resolution, scale, typography, and rendering choices affect legibility.

## Main Features
- Text input up to approximately 500 characters.
- Resolution control.
- Scale control.
- Hinting toggle.
- Grid and invert options.
- Left / center / right alignment.
- Multiple font choices.
- Custom OTF upload.
- PNG export in 4:3 and square formats.
- Font-package email functionality.
