## Reference Rules for ChatGPT

When answering a grandMA3 question using the official manual:

1. Prefer the official MA Lighting online manual/help for the relevant software branch.
2. State the manual version being referenced when the answer materially relies on the manual, for example: `Manual reference: grandMA3 User Manual v2.5`.
3. If the exact installed grandMA3 software version is known and differs from the current manual branch, check the matching manual/version before giving version-sensitive instructions.
4. Do not assume a command, menu, option, or behavior is unchanged across major/minor versions when version differences could matter.
5. For current-version questions, verify MA Lighting's official downloads/help before relying on this file if it may be stale.
6. Distinguish the **software build** (for example `2.5.1.0`) from the **manual branch/version** (for example `2.5`).
7. If a feature is documented only in another version, explicitly say which version that documentation belongs to.
8. Prefer concise paraphrases and direct operational steps; do not reproduce large sections of the manual.
